#### Exercise 2.3
The task was to create a program which turns a hex string *(e.g.
0x48656c6c6f2c20576f726c6421),* and turns it into character output by grouping
every 2 hex digits *(e.g. 48)* and converting them into the right ASCII values.

There's an included `input.txt` file to test it out with, just run:
```c
./a.out < input.txt
```

Or compile the source code in `main.c` if you do not wish to download `a.out`.
