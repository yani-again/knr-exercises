#### Exercise 2.4
The task was to create a function which takes 2 strings *a* and *b*, and removes
any characters within *a* which are also in *b*, making *b* essentially act as a
filter.

###### Note!
I made the program to complete the exercise, as proof-of-concept, rather than
ease of use.

The way to run the program is to provide an input file with just 2 lines, ensuring no empty lines at the end or beginning of the file.

The first line is the input string *a*. The second line is the input string *b*
which *a* is compared against.
